# BotSolUltimate v1
Aumatic bot for solana trading 

The SolanaBot v1 scans new solana tokens based on filters such as liquidity, creation date, token holders, etc. Once the scan finds the token it passes it to the buy function for purchase.

Once the profit or a stop-loss is reached, the script sells the token and sends the result on the discord channel. after the sale the bot starts the purchase procedure again... magical, right?

I'm finishing developing the new version to manage multiple tokens at the same time.
